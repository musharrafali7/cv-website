# Musharraf Ali — Interactive Single-Page CV & Portfolio

An editorial, scroll-driven personal CV and web portfolio built with semantic HTML5, custom CSS3, and vanilla JavaScript. Designed around core UX principles (Hick's Law, Fitts's Law, Law of Proximity, and Peak-End Rule) and a high-contrast 60-30-10 color palette (`#FFF8AD`, `#111111`, `#ADDDFF`).

## Features
- **Full-Width Editorial CV Layout:** Displays personal bio, skills, education, and experience with left-aligned typography and crisp `1.5px` structural borders.
- **Scroll-Driven Desktop & Mobile Showcases:** Interactive bottom-to-top ascent and zoom-in/zoom-out scroll mechanics showcasing the live [Campus Cafe](https://cit331-lab4-campus-cafe-fu7q.vercel.app/) web application across both desktop browser and mobile device frames.
- **Accessible Contact Form:** Inline validation with immediate visual feedback (<400ms response) and persistent input handling.
